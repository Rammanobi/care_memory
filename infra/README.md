# infra/ runbook (Cloud Run, asia-south1)

Run from `caremem/` in Git Bash or Cloud Shell after `gcloud auth login` and `gcloud config set project <project>`.
Every script sources `vars.sh`, the ONE place for `PROJECT` (default `carememory-c1b3f`), `REGION` (`asia-south1`),
`DOCTOR_SITE` (`carememory-doctor`), `PATIENT_SITE` (`carememory-patient`) and `TELEGRAM_ENABLED` (default `0`).
`infra/env/*.env.yaml` use `<project>`, `<doctor-site>`, `<patient-site>`; `render_env` fills them and refuses a leftover
placeholder. `.firebaserc` and `cloudbuild.yaml` hold the same literals (they cannot source bash).
`DRY_RUN=1 bash infra/<script>.sh` prints the gcloud calls and runs nothing (safe anywhere). Never print or paste secret values.

## Order (stage 1: Firebase Hosting `*.web.app` + Cloud Run `run.app`, no custom domain, no LB, no cloud Telegram bot)

| # | Command | Notes |
|---|---|---|
| 1 | `bash infra/00_project.sh` | APIs, Artifact Registry `cm`, bucket `$PROJECT-cm-docs`. Also enable firebase/firebasehosting/identitytoolkit/securetoken (RUNBOOK 3) |
| 2 | `bash infra/10_iam.sh` | service accounts and roles |
| 3 | `bash infra/30_secrets.sh` | creates secrets, generates random ones, lists missing REQUIRED names (`OPENAI_API_KEY`, `DEEPSEEK_API_KEY`). OWNER adds values via a hidden prompt (RUNBOOK 2.2) |
| 4 | `bash infra/35_demo_passwords.sh` | OWNER: copies `DEMO_USER_PASSWORDS` from `.env` to Secret Manager through stdin (never shown). Needed only by `cm-seed` |
| 5 | `bash infra/20_sql.sh` | Cloud SQL (10-15 min) |
| 6 | `bash infra/40_pubsub.sh`, `bash infra/10_iam.sh` (again), `bash infra/50_tasks.sh` | topics, Pub/Sub agent role, queues |
| 7 | `gcloud builds submit --tag $REGION-docker.pkg.dev/$PROJECT/cm/cm:<tag>` | `.gcloudignore` keeps `.env*`, `out/`, `data/uploads/`, `node_modules`, `.git` out of the upload |
| 8 | `IMAGE=<image:tag> bash infra/60_deploy.sh` | worker (with its own URL as `CM_TASKS_BASE_URL`), api, jobs `cm-migrate`, `cm-seed`. One rendered env file per deploy; no DOMAIN needed |
| 9 | `bash infra/80_webhooks.sh` | backup, migrate, health check. Telegram setWebhook only with `TELEGRAM_ENABLED=1` |
| 10 | `gcloud run jobs execute cm-seed --region=$REGION --wait` | demo data (needs `DEMO_USER_PASSWORDS`) |
| 11 | `bash infra/70_scheduler.sh` | `/tasks/drain-outbox` every minute, `/tasks/checkins` daily 07:30 IST |
| 12 | `bash infra/tests/smoke.sh` | checks |

Stage 2 only (custom domain): `85_lb.sh` and `90_telegram_webhook.sh` with `DOMAIN` set (and `TELEGRAM_ENABLED=1` for the bot).

## Secret names (values never in the repo)
Required: `DEEPSEEK_API_KEY`, `OPENAI_API_KEY` (added by hand). For `cm-seed`: `DEMO_USER_PASSWORDS` (35_demo_passwords.sh).
Generated by `30_secrets.sh`: `JWT_SIGNING_KEY`, `PII_MASTER_KEY`, `DB_PASSWORD_APP|ENGINE|READER|ADMIN`.
Only with `TELEGRAM_ENABLED=1`: `TELEGRAM_BOT_TOKEN` (by hand), `TELEGRAM_WEBHOOK_SECRET` (generated).
Optional: `LANGSMITH_API_KEY`, `GMAIL_OAUTH_CLIENT_JSON`, `GMAIL_REFRESH_TOKEN`.
The code reads `DB_PASSWORD`; `60_deploy.sh` maps it from `DB_PASSWORD_APP` (api, worker) or `DB_PASSWORD_ADMIN` (jobs).
With Telegram off, outbound Telegram rows fail with error `auth` (never retried) and `/webhooks/telegram` rejects all calls.

## Entrypoint (`python -m cm <command>`)
`api`, `worker` (uvicorn on `$PORT`), `migrate`, `drain-outbox` (one pass), `sweeper` (stub, exits 0), `nightly --patient X`, `reminders`, `seed`, `eval`.
Env style also works: `CM_ROLE=job CM_JOB=migrate`.

## Database on Cloud Run
`DB_HOST=/cloudsql/<project>:<region>:cm-pg` (unix socket) with `DB_USER` `cm_app` (api, worker) or `cm_admin` (jobs).
If `DB_HOST` is unset, `CLOUD_SQL_INSTANCE` is turned into `/cloudsql/<instance>`.

## Quiet hours (21:00-07:00 IST)
Reminders are deferred at night. For a night demo set `DEMO_IGNORE_QUIET_HOURS=1` on cm-api and cm-worker; it is honoured only when `CM_ENV` is `dev` or `demo`, never `prod`. Turn it back to `0` afterwards.

## Other env names (placeholders in `api.env.yaml`)
`COOKIE_SECURE=1`, `CORS_ORIGINS`, `CM_ALLOWED_HOSTS`, `CM_COOKIE_DOMAIN` (leave empty), `PUBLIC_BASE_URL`.
